## Clean audio

https://podcast.adobe.com/en/enhance

Python Libraries
noisereduce - Most popular and user-friendly

GitHub: timsainb/noisereduce
Simple API for stationary noise reduction
Works well for consistent background noise (fans, hums, etc.)
Easy to use: nr.reduce_noise(y=audio_data, sr=sample_rate)

Facebook Denoiser - High-quality real-time enhancement

GitHub: facebookresearch/denoiser
Deep learning-based speech enhancement
Excellent for speech denoising
Real-time capable

SpeechBrain - Comprehensive toolkit

GitHub: speechbrain/speechbrain
Includes speech enhancement, separation, and denoising
Pre-trained models available
More advanced but very powerful

asteroid - Audio source separation

GitHub: asteroid-team/asteroid
Great for separating speech from noise/music
Multiple pre-trained models
Research-oriented but production-ready

Specialized Tools
RNNoise - Lightweight real-time solution

GitHub: xiph/rnnoise
C library with Python bindings
Very fast, designed for real-time use
Good for voice applications

librosa + scipy - Building blocks approach

Combine with spectral gating techniques
More control but requires more audio processing knowledge
Good for custom solutions
